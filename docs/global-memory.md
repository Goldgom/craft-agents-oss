# 全局持久化记忆

TokenBird 默认在智能体手动或自动压缩成功后，调用当前连接的小模型提取稳定偏好、事实、决策和复用经验。只处理上次压缩后新增的用户和助手文本，每次最多输入最近 48,000 个字符、保存 12 条记忆，不复制完整聊天或工具输出。提取会增加一次模型请求；失败会记录后端日志，压缩结果仍继续处理。

记忆保存在 `~/.tokenbird/memory/compactions/*.json`，使用 `TOKENBIRD_CONFIG_DIR` 时跟随该目录。每条附带工作区、会话、时间和原文证据。同一个后端配置目录内的所有会话和工作区共用它；不同用户或租户应使用各自的配置目录。现有超级智能体的工作区 Memory 库保持独立。

后续消息按关键词检索，去重后最多注入 6 条相关记忆，支持中文二元词匹配。记忆属于历史数据，不授予权限，也不覆盖当前用户要求。模型提取和证据匹配不能保证事实正确，需结合当前情况核实。

在后端的 `config.json` 设置：

```json
{ "memoryMode": "tokenbird" }
```

也可以设置环境变量 `TOKENBIRD_MEMORY_MODE`，优先于配置文件：

| 值 | 行为 |
| --- | --- |
| `tokenbird` | 默认；压缩后提取并写入 TokenBird 全局记忆，后续消息检索 |
| `native` | 停止 TokenBird 自动写入和注入，由所选工具自身的原生记忆配置负责；不会为不支持原生记忆的工具模拟该功能 |
| `off` | 关闭 TokenBird 全局记忆自动写入和注入 |

修改配置文件从下一次操作生效；修改进程环境变量需要重启后端。切换模式保留已有记录，不执行数据迁移。工具自身的原生记忆和项目 MEMORY.md 是独立功能，`off` 不修改它们或现有工作区 Memory 库。需要停用原生记忆时，同时关闭对应工具的原生选项。删除全局记忆可在后端停止后删除 `memory/compactions` 下的相应 JSON 文件。
