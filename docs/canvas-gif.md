# 选区生成 GIF

在图片处理画布中框选图片，点击选区侧栏或编辑工作台的「一键生成并保存 GIF」。生成后显示动画预览并保存文件，无需配置图片生成服务。

- **循环缩放动效**：合并选区内可见图层，生成轻微放大再还原的循环动画。默认 20 帧、每帧 100 毫秒。
- **图层逐帧合成**：每个可见图层作为一帧，按图层从底到顶排列，需要 2–60 个可见图层。每帧独立显示，不与其他帧混合或剪贴；保留图层透明度和蒙版。
- 可设置帧间隔、最大边长和循环次数。0 表示无限循环，-1 表示仅播放一次，正整数表示重复次数。
- 保持长宽比，不放大小图；默认最大边长 512，最多 1024 像素。保留选区形状和孔洞；GIF 使用二值透明，半透明像素以 50% 为阈值。帧间隔按 GIF 的 10 毫秒精度取整。
- 最多 2400 万总帧像素，输出最多 8 MB。导出不修改源图层、选区和撤销记录。这是本地动画制作，不调用图生视频模型。

## AI 接口

沿用 `canvas_tool`。先通过 `get_state` 查看画布，并用 `set_selection` 或其他选区动作选择范围，再执行：

```json
{
  "action": "generate_gif",
  "gifMode": "zoom",
  "frameCount": 20,
  "frameDelay": 100,
  "repeat": 0,
  "maxSize": 512,
  "outputPath": "C:\\Exports\\selection.gif"
}
```

`gifMode=layers` 时可指定 `layerIds` 数组决定帧顺序，省略时使用所有可见图层的画布顺序。`frameCount` 仅用于缩放动效。桌面 `outputPath` 必须为绝对路径且后缀为 `.gif`，父目录须已存在；已有文件不会被覆盖。不传路径时桌面返回 Base64、MIME、尺寸、帧数、时长和字节数。Web 客户端沿用浏览器文件保存流程，不会写入服务端路径。

使用已有画布授权流程；可申请的限制经用户批准后继续原调用，完全控制遵循应用权限总开关。
