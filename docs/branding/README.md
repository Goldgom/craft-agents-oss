# TokenBird 品牌图标

- `tokenbird-icon-source.png`：TokenBird（词元鸟）应用图标原稿。
- `tokennest-logo-source.png`：TokenNest（词元窝）登录入口图标原稿。
- `tokenbird-icon-transparent.png`：已移除背景及右下角标记的应用图标透明母版。
- `tokennest-logo-transparent.png`：已移除背景的词元窝图标透明母版。

运行 `bun run scripts/generate-brand-icons.ts` 会从透明母版生成 Electron、Windows、macOS、Linux、Android 和 WebUI 所需图标。
