# 视频制作

顶部工作台切换菜单新增「视频制作」。视频项目、人物/场景/风格记忆、素材和任务记录保存在当前工作区的 `video/studio.json` 与 `video/assets/`，重新打开软件后继续可用。

## 从脚本生成视频

1. 在「生成服务」添加 Runway、Luma 或 Seedance 服务，填写该账户的 API Key、模型与 API 地址。自定义兼容服务需要自行填写其仍支持的 Videos 接口地址与模型。密钥使用已有凭据系统加密保存，不写入项目文件或前端持久化存储。
2. 在「人物 / 场景记忆」上传参考图片并填写特征描述。可默认启用，也可以在项目、镜头中指定记忆。明确选择时使用所选记忆；未选择时使用默认启用的记忆。生成会带入对应描述与接口支持的图片参考。
3. 新建项目，选择视频服务、比例、偏好和脚本分析的 AI 连接/模型。「导入脚本并分镜」读取 TXT/Markdown，并使用所选连接的实际 Agent 会话提取记忆与镜头；尚未选择 Agent 时保留脚本并提示配置。
4. 可以编辑镜头提示词、时长、记忆与字幕，调整顺序，或者为镜头选择现有视频素材。
5. 「一键生成完整视频」在没有分镜时先分析脚本，随后逐镜生成、下载验证，再统一画幅和音轨并合成 MP4。「合并现有分镜成片」直接使用已有镜头。「镜头字幕」生成带时间轴的 SRT 并烧录到成片；当前不合成配音，可导入音频添加背景音乐。
6. 在任务记录查看进度、失败原因、分析会话及结果。成片和素材支持预览、分块导出。原始素材保留，剪辑生成独立文件。

已生成镜头会记录提示词、时长、偏好、有效记忆及图片引用、画幅、供应商和模型的生成参数摘要。相同参数可复用；参数变化或旧镜头缺少摘要时，「一键生成完整视频」会在提交任何新付费镜头前提示先明确重新生成受影响的镜头，不会把旧片静默当成新偏好产物，也不会自动再次扣费。修改镜头标题或字幕不需要重新生成视频。手动选择的视频素材保持原样；「合并现有分镜成片」明确使用当前素材，不发起新的视频生成。

参考图能改善一致性，最终效果取决于服务和模型。当前 Runway、Luma、兼容适配器使用单张参考图；Luma 需要可公开访问的 HTTPS 图片地址；支持 `reference_image` 的 Seedance 模型可传多张人物/场景图。不支持的组合会在请求前明确报错，不会悄悄丢弃参考图片。各模型还有时长、比例和提示词长度限制。

任务在工作区所在服务端后台执行，页面切换不停止任务。重启后进行中的任务标记为中断，重试使用已保存的供应商任务 ID 与完成镜头。请求已发出但提交结果不明时，需要先核实供应商任务，再明确重新提交，避免自动重复计费。取消会停止本地处理，并尝试取消供应商任务；供应商是否停止及费用以其状态为准。

## 剪辑接口与模型工具

「素材与剪辑」支持时间截取、视频拼接、尺寸调整、画面裁切、旋转、变速、静音、音量、音频/画面提取、MP4 转码、字幕、图片水印和背景音乐。视频拼接统一尺寸、帧率与音频格式，为无声片段补静音轨。界面导入单个素材上限 64 MB、记忆图片上限 20 MB；生成视频单段下载上限 512 MB。较大的生成视频按块预览和导出，不会一次塞进 RPC 消息。

RPC 为 `video:execute`，使用 `{action,args}`；连接绑定工作区，不能通过参数访问另一个工作区。共享类型位于 `packages/shared/src/video/types.ts`。模型通过统一注册的 `video_tool` 调用相同服务，内置 `video-production` Skill 与 `references/editing.md` 描述具体参数和完整流程。工具不向模型提供密钥，也不能修改供应商凭据。

权限不足时沿用原调用的授权弹窗；完全控制沿用应用总开关。Super Agent 节点在自身模型进程中分析脚本并保存分镜；工作台的分析按钮可以创建独立 Agent 会话。选定容器的节点通过自身 Bash 环境运行 FFmpeg，视频工具不回退宿主机执行。

## FFmpeg 资源

Windows 与 Linux 的 x64/arm64 使用固定版本、SHA-256 校验的 LGPL 发行包，同时包含 `ffmpeg`、`ffprobe`、发行方许可资料与来源说明。资源构建会校验缓存并将真实二进制复制进软件包；Windows 打包检查缺失的 FFmpeg 资源会失败。macOS 构建需要通过 `TOKENBIRD_FFMPEG_BUNDLE_DIR` 提供包含校验清单和许可资料的已审查运行时。

```powershell
bun run scripts/build/ffmpeg.ts
bun run electron:build:resources
```

两个工具支持独立覆盖：`TOKENBIRD_FFMPEG_PATH`、`TOKENBIRD_FFPROBE_PATH`。处理使用参数数组启动子进程，支持取消、超时、输入检查与输出限制。开发、Electron 与完整无头服务构建共用运行时资源；精简 CLI 包不默认携带视频运行时。

相关验证包含 `providers.test.ts`、`service.test.ts`、`agent-analysis.test.ts`、`ffmpeg.test.ts`、`workflow-media.test.ts`、`video-permissions.test.ts` 与 `scripts/test-studio-video.ts`。实媒体工作流使用真实 FFmpeg 和模拟供应商，真实付费视频生成需要配置可用密钥再验证。
