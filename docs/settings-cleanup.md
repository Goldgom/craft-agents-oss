# 设置整理记录

## 检查结论

检查了设置注册表、桌面和移动端菜单、页面组件、RPC、配置存储，以及模型提示词和工具的实际读取路径。

默认设置菜单原有 19 个入口（用量和充值已有独立入口），本次合并后为 17 个。问题主要是相关配置分散、重复维护导航列表和遗留页面；本次检查涉及的配置项仍有实际消费者，因此没有删除用户已保存的配置。

## 已完成的合并和删除

| 原有内容 | 处理 | 原因 |
| --- | --- | --- |
| 提示词、总提示词两个设置入口 | 合并至“提示词”；总提示词预览默认折叠 | 同一工作流中管理工作区指令、系统附加指令、能力说明及最终提示词来源 |
| 输入、快捷键两个设置入口 | 合并至“输入与快捷键”；快捷键参考默认折叠 | 发送键和发送快捷键说明应在同一页面，说明随发送键配置变化 |
| 工作区默认权限、模式切换；权限页面的探索规则 | 集中到“权限” | 权限模式和规则应一起配置；工作区页面保留名称、图标、默认数据源、目录和本地 MCP |
| 应用中的内置浏览器、读取数据源指南开关 | 移到“工具” | 这些选项控制工具行为 |
| 外观中的丰富工具描述 | 移到“工具” | 该选项会改变发给模型的工具参数元数据，不只是界面外观 |
| 无人引用的旧 `renderer/pages/ShortcutsPage.tsx` | 删除 | 与设置目录中的快捷键实现重复且已脱离入口 |
| 手工维护的导航占位页面列表 | 改为从设置注册表生成 | 防止新增或合并页面后两份列表不一致 |
| 总提示词、快捷键独立整页实现 | 提取为合并页中的内容组件 | 删除重复页头和滚动容器 |

保留 `settings/promptOverview` 和 `settings/shortcuts` 路由作为兼容别名，打开合并后的页面并展开对应参考内容。侧栏会选中合并后的入口。桌面菜单、移动端菜单和设置导航使用相同的入口列表。

## 保留的相似选项及原因

| 相似内容 | 保留原因 |
| --- | --- |
| 应用网络代理、个人偏好代理 | 应用代理控制实际网络配置；个人偏好仅告诉模型联网操作优先采用哪个代理 |
| 内置浏览器开关、浏览器能力说明 | 前者决定工具是否可用；后者决定系统提示词是否包含使用指导 |
| 工作区提示词、系统附加指令、个人偏好备注 | 作用范围和保存位置不同，不能合并为同一配置值 |
| AI 全局默认、工作区覆盖 | 分别提供应用默认值和工作区例外，保留继承关系 |
| AI 优化、性能设置 | 前者控制上下文与提示词缓存等模型行为；后者控制运行时与 MCP 资源限制和诊断 |
| 远程服务器、服务器设置 | 前者管理客户端连接目标和 SFTP；后者管理启动位置与本机服务监听 |
| AI 连接、凭证管理 | 前者管理模型服务；后者管理工作区使用的原生账号和凭证 |
| 主题、主题包、工作区主题覆盖 | 分别控制配色、主题资源包和工作区例外 |
| 消息集成、协作管理 | 分别连接外部消息平台和管理协作工作流 |
| 数据源、工具目录 | 数据源负责连接和授权；工具目录展示最终可用工具与状态 |

标签、使用指南和独立用量/充值功能也有各自用途，本次保留。
