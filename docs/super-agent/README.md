## 核心设计

- 每个工作区保存一个团队，恰好一个主智能体，至少一个工作节点。
- 每节点使用一个持久模型会话，节点内部串行，不同节点可以并行。
- 主智能体维护计划、派工、核验和汇总；工作节点执行任务、通信和提交产物。
- 后台服务负责排队、限速、状态持久化、环境准备和工具权限检查。
- 从完整回复解析末尾单个动作块，独立限制显示文字和控制块，持久化实际动作回执。
- 脚本执行绑定运行、任务和计划；终态直接交主节点处理，正常完成处理轮次后确认投递。
- 运行期间持续核对真实会话，丢失完成事件时结算未知结果并安排核验，保留原会话与产物供检查。
- 持续工作在已有授权目标内推进计划；全队连续空闲 30 分钟后触发后台自检。
- 任务完成表示工作节点提交了本轮结果；计划完成还需要主智能体核验目标。

本次已修复长回复丢动作、脚本终态交付、运行存活对账和动作失败不可见四项可靠性问题。任务依赖图、自动补位、结构化验收证据及更好的节点选择仍是后续改进。

维护时应同时更新设计说明和使用说明，并核对相关类型、校验规则及调度测试。
