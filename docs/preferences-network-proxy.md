# 网络代理偏好

在 **设置 → 偏好 → 网络代理** 中填写偏好代理地址，例如 `http://127.0.0.1:7890` 或 `socks5h://127.0.0.1:1080`。设置会自动保存，清空地址即可关闭。

开启新对话后，用户偏好提示词会告知模型：执行网络请求、下载、安装依赖等操作时，如果工具支持显式代理参数，应优先使用这个代理。代理不可用或工具不支持时，应说明限制，而不是静默切换到直连。已有会话可能固定了启动时的偏好，修改后请开启新对话。

此设置仅指导模型使用网络工具，不会自动改变 TokenBird、模型 API 或系统的代理配置，也不保证所有工具都支持代理。连接远程服务器时，`127.0.0.1` 指执行工具的服务器或运行环境，而不是桌面客户端。地址内容会发送给模型，请避免填写不希望发送给模型的凭据。

偏好保存在 `preferences.json` 的 `preferredProxy` 字段；保存时保留界面未编辑的语言、性能、提示词、启动服务器等设置。也可以明确告诉模型代理地址，通过 `update_user_preferences` 工具更新；传入空字符串可清除偏好。
