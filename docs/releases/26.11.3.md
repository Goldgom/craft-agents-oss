# TokenBird 26.11.3

- 新增按操作 ID 恢复的宿主接口，检查原会话、独立操作回执归档和原会话磁盘存档；核对身份及哈希，不用摘要或重跑替代原记录。
- 新操作派发前同步保存原输入，结果到达时独立保存原输出，减少会话裁剪、上下文压缩或重启后丢失核验依据。
- 明确区分执行成功、已结束但失败、独立确认未执行和结果仍未知。修复验证任务自己的操作时不要求另一个验证任务先完成，避免递归验证链。
- 恢复记录请求 ID、操作者、证据来源与哈希及前后状态；相同请求幂等，结果可查询。独立证据协调也记录操作者与证据哈希。
- 宿主自动有界检查可确认的终止回执，不消耗模型调用；相同证据不反复扫描。真实活跃执行、外部副作用不明、回执缺失/不匹配继续保留阻碍。
- 只结清证据支持的具体调用；保留任务失败记录、输出、写入和其他未知操作的资源。恢复执行状态不自动通过业务验收。
- 同步恢复工具 Schema、提示词、内置协作说明、权限约定和回归测试；保留完全控制、权限弹窗、通信拓扑、串行模型和所选执行环境。

Windows 交付目标：x64 NSIS EXE 安装包。安装包及内置运行时校验与真实安装、LumaStack 功能验收分别记录；本次不宣称已恢复报告中的特定历史操作。
