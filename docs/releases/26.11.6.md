# TokenBird 26.11.6

- 新增“恢复任务”：重建执行子节点，保留主要节点进度、任务板、计划、通信记录、报告及已完成成果。
- 启动后自动接续中断工作，沿用原任务 ID、检查点和执行证据；用户停止及取消继续生效。
- 修复 Pi 将 Bash 读取显示为 Read 时改变执行身份、导致回执哈希不匹配的问题。历史回执仅在原始证据完整匹配时修复并记录审计。
- 恢复前保存状态备份，保留通信链预算、重试截止时间和脚本结果通知身份；旧会话不能发起新操作。
- 未知写入及未确认停止的程序继续阻塞相关资源，独立任务可继续推进。
- 修复自定义 OpenAI 兼容模型被默认 8192 输出额度截断的问题；普通对话由上游决定输出上限，摘要压缩等显式预算继续保留。
- 模型返回空正文且没有工具调用时明确提示未完成；重试后的空响应不再误报“恢复成功”。

Windows 交付目标：x64 NSIS EXE 安装包。构建与包内校验不代表已替换用户安装的客户端，也不代表已完成原 LumaStack 拖拽问题的验收。
