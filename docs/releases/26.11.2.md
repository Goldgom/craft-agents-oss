# TokenBird 26.11.2

## 超级智能体

- 任务完成后自动显示勾选，任务列表、进度统计和模型工作列表使用同一完成判定。待验收、结果未知、部分应用和版本过期的任务保留未完成状态。
- 默认将有界任务交给一个执行节点完成并自检，复用当前版本的检查点和结果，减少重复派工、需求改写和管理汇报。
- 相同工作状态下不再反复启动空闲巡检；新增输入、通知和手动检查仍可触发处理，巡检指纹支持跨重启保留。
- 后台规划及派工协调可以显式结束没有新增工作的内部轮次，避免工具执行已结束后因缺少最终答复反复续跑。
- 上下文按需提供历史节点和证据详情；排队与健康详情显示实际占用任务、资源和未决操作。
- 整合主节点、后台规划、派工协调的职责与通信拓扑、准备阶段监督、共享板归档及恢复、持久检查点与原始操作回执。
- 保留权限申请弹窗、内置技能独立读取及完全控制约定。未知写入结果须先核验，不能通过重置或盲目重试绕过。

## 会话与附件

- 将节点间消息与过程文本放入可展开的活动区域，避免将内部说明提升为用户最终答复。
- 普通子任务真正完成且没有认证、排队或后台工作时退出活动列表，保留历史查看入口。
- Android 使用系统文档选择器处理附件和多选；图片缺少 MIME 时按文件类型回退识别，桌面输入与 WebUI 共用识别逻辑。

## Windows 交付

- 本次构建目标为 Windows x64 NSIS EXE 安装包，版本号为 26.11.2。
- 安装包校验包括主程序版本、构建文件一致性、任务完成与恢复功能标记、内置技能、运行时及更新清单校验值。
- 本地构建、包内运行时检查与实际安装后的完整产品验收分别记录；未完成的验证不作为功能已上线的证明。
