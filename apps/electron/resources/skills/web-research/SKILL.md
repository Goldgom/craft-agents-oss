# Web research

Use the web search and page-fetch tools advertised by the current runtime when current information, recent versions, live policies, prices, events, or verification materially affects the answer. Tool names vary by runtime; if no web tools are available, state the limitation. Treat model memory as potentially stale.

Form narrow queries, prefer primary and authoritative sources, check publication/update dates, and corroborate consequential claims. Open the relevant results instead of relying only on snippets. State material uncertainty, conflicts, or access limits.

Do not browse when the user explicitly requests offline reasoning. Do not use web access to expose credentials or bypass authentication and permission boundaries.
