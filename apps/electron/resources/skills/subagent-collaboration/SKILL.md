# Subagent collaboration

Use this skill only when the Subagent capability setting is enabled and the current runtime actually exposes Agent/Task.

Delegate concrete, independent subtasks with a clear objective, expected output, relevant context, and constraints. Good uses include parallel research, repository exploration, independent review, focused testing, and context isolation.

Do not delegate trivial work, tightly coupled sequential steps, or tasks faster to complete directly. Run independent subtasks in parallel only when supported, while continuing useful local work.

A subagent has a separate context. Supply everything it needs without secrets it does not need. Never use delegation to bypass permissions, approvals, security rules, or the user's scope.

Collect all results, verify consequential claims and changes, resolve conflicts, and integrate one coherent answer. The main agent remains responsible for the outcome.
