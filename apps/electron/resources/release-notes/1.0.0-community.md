# v1.0.0-community.1 — Craft Agents Community Edition（社区版）

This release introduces the Community Edition: an Apache 2.0, local-first and self-hostable Agent workspace for desktop, server, CLI, WebUI, and Android.

## Features

- **Run Agent workspaces anywhere** — Use the Electron desktop app, headless server, CLI, WebUI, or the new Android WebView client. Remote workspaces can be added and managed from the desktop, with SSH/SFTP support and safer session/MCP process recovery (`5ba9f2de`, `132c626a`, `eef3661d`, `921fe5ea`).

- **Projects, Tasks, and Kanban workflows** — Organize sessions and assets in Projects, track durable Tasks on a customizable Kanban board, and run dependency-aware task graphs through the Conductor with resumable child sessions and acceptance-criteria repair loops (`f4e172bf`).

- **Agents, Skills, and script automations** — Configure workspace Agents, use bundled authoring Skills, and schedule HostedScript or dedicated Script monitors with least-privilege permissions. Background agents can continue across turns and report completion in the UI (`320f9f1e`, `11a7a83a`, `0ac0447e`).

- **Messaging integrations** — Connect QQ Bot and WeCom, including group conversations and rich interactions such as voice and file messages; the messaging gateway also supports existing WhatsApp and Telegram workflows (`e11da39b`, `c32c9083`, `d60cb9fc`, `0873471f`).

- **Remote browser and workspace collaboration** — Remote agents can control the local browser through a capability-aware bridge, while browser tabs remain isolated by workspace. Sessions can be transferred between local and remote workspaces (v0.10.0–v0.11.2).

- **Open and extensible integrations** — Import and export MCP configurations and workspace data, manage tools and sources from the UI, and use custom model endpoints plus built-in provider connections (`e48a4d8e`, `386d7036`, `50444dea`).

- **Built for community customization** — Ships with additional themes (including dafy-whale, Galaxy, and Light+), a performance monitor for Agent/MCP subprocesses, and an Android runtime bundle that can run the Bun backend and MCP services locally (`32e68595`, `b2019460`, `342c04ea`).

## Improvements

- Source/API tool guide enforcement can be enabled or disabled from Settings → Tools, making self-hosted source workflows easier to adapt while preserving the safe default.
- Pi and Claude runtimes, model catalogs, OAuth providers, and search integrations have been refreshed through the 0.10–0.12 release series, including GPT-5.6, Kimi K3, GitHub Copilot, and improved ChatGPT web search support.

## Breaking Changes

- None. Community Edition builds use the `1.0.0-community.1` version identifier and do not depend on Craft-hosted services.
