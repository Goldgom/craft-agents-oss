## Improvements

- Pi SDK fixes bundled with 0.84.4: GitHub Copilot sign-in no longer trips model-policy rate limits, Kimi cached tokens are billed as cache reads, Bedrock replays redacted reasoning from non-Anthropic models, large tool results that cross the auto-compaction threshold are compacted before the next model call, and OpenRouter reasoning-effort controls follow the model's metadata (`70bda09b`)
- The `web_search` and `web_fetch` tools on the Pi path now build their parameter schemas with the SDK's own TypeBox (Pi 0.83.0 moved to the `typebox` 1.x package), so model-emitted argument types (for example a numeric string for `count`) are coerced the same way as for built-in tools instead of being rejected (`70bda09b`)
- **OSS mirror builds and CI are green again** — `bun install --frozen-lockfile` and `bun run validate:ci` had failed on a fresh clone of [craft-agents-oss](https://github.com/craft-ai-agents/craft-agents-oss) for the last five release syncs: the exported `bun.lock` still pinned internal-only workspaces, `tsconfig.base.json` and the i18n coverage check were missing from the export, and `typecheck:all` required the internal-only Pages worker. The sync now regenerates the lockfile for the exported workspace set, both files are exported, and `typecheck:all` skips `workers/pages` when it is absent. Thanks to [@Code-MonkeyZhang](https://github.com/Code-MonkeyZhang) (Yufeng "Jonathan" Zhang) for surfacing the lockfile and `tsconfig.base.json` gaps in [craft-agents-oss#1034](https://github.com/craft-ai-agents/craft-agents-oss/pull/1034) (`9732bf49`)

## Bug Fixes

- Anthropic and Amazon Bedrock connections on the Pi path no longer default to the retired `claude-opus-4-5-20251101` snapshot — the deprecated ID inherited the rank of its Opus 4.8 replacement and sorted ahead of it. New connections and provider-synced backfills now land on Opus 4.8 as intended (`42832c8e`)
- The What's New list reads only versioned release-note files, so the pending-notes template that ships alongside them can no longer surface as a phantom `next` version (`f44645f2`)
