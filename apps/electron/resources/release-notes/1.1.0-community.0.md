# v1.1.0-community.1 — Craft Agents Community Edition（社区版）

This release consolidates the 0.13.x upstream updates into the next Community Edition release, while keeping the local-first desktop, server, CLI, WebUI, and Android workflows.

## Features

- **Pages Beta** — Build persistent mini apps such as dashboards, reports, trackers, and small tools. Pages have project-aware sidebar navigation, embedded rendering, previews, and their own key-value and time-series data store.

- **Secure page actions and sharing** — Pages can call approved API, MCP, or workspace-script capabilities through expiring, content-bound grants. Actions are audited, credentials remain hidden, and pages can be published as view-only, optionally password-protected copies with explicit data-snapshot opt-in.

- **Scheduled page refresh** — Attach a validated cron schedule and workspace script to a page. Refreshes run deterministically in the background, enforce the five-minute minimum interval, and surface failures in the page instead of silently dropping them.

- **Automation and workspace tooling** — Adds script actions, page refresh triggers, page data tools, source reconnect prompts, and project filtering for page libraries. Existing HostedScript, Agents, Skills, Android, QQ Bot, and remote-workspace capabilities remain available.

- **Claude Fable 5.1** — Adds Anthropic's Fable 5.1 model with the 1M-token context window and Bedrock US/EU/global inference-profile mappings. Opus 4.8 remains the default model.

## Improvements

- **Claude Agent SDK 0.3.220 → 0.3.258** — Improves thinking-token reporting, per-model cost accounting, and MCP resource-link support.
- **Community packaging** — Aligns all workspace package, Electron, WebUI, CLI, and Android version identifiers at `1.1.0-community.1`.
- **Security and reliability** — Adds path-traversal-resistant page storage, render and publishing rate limits, bounded page data growth, credential-free logs, sandboxed rendering, and safer MCP runtime handling.

## Bug Fixes

- Restores ChatGPT Plus OAuth resolution after the Pi SDK credential-shape change.
- Corrects Amazon Bedrock IAM credential resolution so stored IAM configuration no longer shadows environment and instance-profile credentials.

## Breaking Changes

- None. Community Edition builds remain self-hostable and do not depend on Craft-hosted services.
