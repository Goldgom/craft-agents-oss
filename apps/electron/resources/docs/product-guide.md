# 词元鸟本地功能指南

这是一份随词元鸟安装包提供的离线功能说明。应用每次启动都会将它同步到 `~/.tokenbird/docs/product-guide.md`，帮助菜单、页面中的“了解更多”和设置里的文档入口都会打开本地“功能指南”页面，不依赖远程网站。

## 1. 会话与任务

- **多会话并行**：每个会话保存独立的消息、上下文、模型选择、权限模式和工作目录，可同时推进多个任务。
- **收件箱与归档**：通过状态区分正在处理和已经关闭的会话；置顶或标记重要会话，便于稍后继续。
- **草稿与附件**：输入内容和附件草稿会按会话保存。可附加图片、PDF、Office 文档、代码和其他本地文件供模型分析。
- **多面板与独立窗口**：在同一窗口并排查看会话或浏览器，也可以将页面打开到新的聚焦窗口。
- **会话分享**：将允许分享的会话发布为访问链接；分享前检查其中是否含有密钥、个人信息或内部文件。

## 2. 工作区

- **环境隔离**：不同工作区拥有各自的会话、来源、技能、标签、状态、提示词和权限配置，适合把个人、团队与不同项目分开。
- **工作目录**：会话可以绑定本地目录，文件工具和命令会以该目录为主要上下文。
- **工作区提示词**：为整个工作区定义长期规则，也可查看最终组合后实际发送给模型的提示词。
- **远程工作区**：连接已配置的词元鸟服务器，在桌面端或 WebUI 使用远端工作区。远端文件和能力以服务器实际提供的范围为准。

## 3. AI 连接、模型与思考级别

- **多种连接方式**：支持 TokenNest、API Key、订阅账号及兼容接口等连接；具体可用方式以“设置 → AI”当前显示为准。
- **模型发现与选择**：连接成功后读取可用模型，可设置全局、工作区或单会话模型。
- **思考级别**：根据速度、费用和任务难度调整推理投入。简单问答使用较低级别，复杂分析或编码使用较高级别。
- **连接检测与余额**：支持的连接可测试可用性、刷新模型并查询余额；检测成功只代表当前测试请求成功。
- **服务后端**：在“设置 → 人工智能”中可为默认服务或每个连接选择兼容的 Pi、Codex 或 Claude Code 后端；切换后，活动会话会在下一条消息前安全重建运行时。

## 4. 权限与安全模式

- **探索模式**：偏向只读调查，适合先查看代码、文件和数据。
- **请求编辑**：需要修改或执行高影响操作时向用户确认，适合日常协作。
- **执行模式**：在配置允许的边界内直接执行，适合明确且可信的自动化任务。
- **权限规则**：可按命令、文件路径、MCP 工具或 API 请求设置允许、询问和拒绝规则。来源还可以拥有自己的细粒度权限文件。
- **敏感信息保护**：密钥保存在本地凭据存储或受控配置中；分享会话、日志和截图前仍应人工复核。

## 5. 来源（Sources）

来源把外部服务或本地数据接入会话，使智能体能够读取或操作真实信息。

- **MCP 来源**：连接本地或远程 Model Context Protocol 服务，加载其结构化工具。
- **REST API 来源**：配置基础地址、认证方式、测试端点和允许的请求范围。
- **本地文件夹来源**：授予指定目录访问能力，例如代码仓库、知识库或数据目录。
- **来源说明**：每个来源可包含 `guide.md`，记录用途、限制、调用习惯和必要上下文。
- **启用范围**：可按工作区或会话选择来源；停用来源会阻止其工具参与当前任务。

创建来源前先明确最小访问范围，只授予完成任务所需的权限。更详细的格式参考同目录的 `sources.md` 与 `permissions.md`。

## 6. 技能（Skills）

- **可复用操作规范**：技能用 `SKILL.md` 描述何时触发、如何工作以及需要读取的参考资料。
- **按需调用**：在消息中提及技能，或在任务符合技能范围时由智能体加载。
- **内置能力技能**：浏览器、网络研究、结构化数据、文档、Pages、预览、会话协作、消息渠道、资源迁移和远程操作等详细工作流随应用内置；系统提示词只保留简短索引，命中任务时再读取对应技能，从而降低每轮 token 消耗。
- **工作区管理**：技能可随工作区维护，便于团队把固定流程沉淀为可审查的本地文件。
- **配套资源**：技能目录可以包含脚本、模板、示例和参考文档，避免每次任务重复搭建。

完整结构和编写规则见本地 `skills.md`。

## 7. 智能体与协作

- **主智能体**：负责与用户沟通、理解目标并整合最终结果。
- **子智能体**：可将边界清晰的工作拆给独立智能体并行处理，主智能体负责协调和验收。
- **Subagent 协作开关**：在“设置 → 提示词总览 → 人工智能能力配置”中开启后，系统提示词会指导主智能体主动判断何时调用子智能体、并行推进以及验收整合结果；默认关闭。
- **自定义智能体**：为固定角色配置独立说明和工具范围，例如测试、资料整理或代码审查。
- **协作管理**：管理工作区内可用的协作能力和相关状态；是否可以并行取决于当前运行环境与配置。

## 8. 内置工具

- **文件与代码**：读取、搜索、创建和修改文件，检查版本差异，并在允许时运行命令。
- **浏览器**：打开网页、读取页面结构、点击、填写、上传、截图和检查网络活动。登录状态保存在对应浏览器环境中。
- **搜索**：在启用且配置可用时搜索公开信息，并将来源链接带回会话；没有服务商原生搜索能力时默认使用 Bing，浏览器地址栏中的普通文本也会交给 Bing 搜索。
- **数据转换**：使用脚本处理 JSON、CSV 等数据，生成适合预览或继续分析的结果。
- **模型调用**：在支持的场景中调用另一个模型完成独立转换、分类或分析任务。
- **会话工具**：搜索历史会话、发送消息、创建会话或在智能体之间传递任务上下文。

工具是否可用以“设置 → 工具”和当前会话实际显示为准。

## 9. 浏览器与内容预览

- **网页浏览**：浏览器面板可作为独立页面或会话旁的辅助面板使用。
- **Markdown**：支持标题、列表、表格、代码块、任务列表和链接等常用格式。
- **Mermaid 图表**：可以预览流程图、时序图、状态图等 Mermaid 内容。
- **数据表格**：小型数据可直接渲染，大型数据可先写入文件再分页展示。
- **HTML、图片与 PDF**：针对不同内容提供专用预览；HTML 会在隔离环境中显示以降低脚本风险。
- **Office 文档**：支持把常见办公文档作为附件读取，实际解析效果取决于格式和运行平台。

本地目录中的 `browser-tools.md`、`markdown-preview.md`、`data-tables.md`、`html-preview.md`、`image-preview.md` 和 `pdf-preview.md` 提供详细格式。

## 10. 页面（Pages）

- **结构化成果页**：智能体可以创建比聊天消息更适合长期查看的页面，如报告、看板、说明页或小型交互内容。
- **本地编辑与预览**：页面资源随工作区保存，可在应用内预览和继续修改。
- **发布与分享**：需要外部访问时可发布页面；发布属于外部状态变更，应先确认内容和访问范围。

页面格式和能力边界见本地 `pages.md`。

## 11. 状态与标签

- **状态**：定义会话工作流，例如待处理、进行中和已完成。开放状态通常出现在收件箱，关闭状态进入归档。
- **标签**：用颜色和层级对会话分类，可附带文本、数字、日期等值。
- **自动匹配**：标签规则可根据消息内容提取并应用值，适合项目编号、客户、优先级等结构化信息。
- **筛选与组织**：状态和标签共同用于快速定位会话，不会替代来源权限或文件访问控制。

配置格式见本地 `statuses.md` 和 `labels.md`。

## 12. 自动化与后台任务

- **事件触发**：应用事件、会话事件、标签变化等可触发操作。
- **定时任务**：使用计划表达式周期性创建提示任务。
- **提示动作**：自动创建或驱动会话执行指定工作。
- **Webhook**：向配置的服务发送 HTTP 请求；密钥应通过环境变量或安全配置注入。
- **条件、重试与限流**：可限制触发条件，并对暂时性失败执行受控重试，避免任务风暴。
- **后台运行**：部分任务可在后台继续，但仍受模型连接、权限、网络和服务器状态影响。

详细事件和配置示例见本地 `automations.md`。

## 13. 消息渠道

- **外部聊天接入**：可将会话连接到当前版本支持的 Telegram、WhatsApp、飞书/Lark 等渠道。
- **配对与路由**：根据工作区、群组、话题或会话配置消息去向。
- **富文本与附件**：不同平台能力不同，词元鸟会在平台允许的范围内转换回复格式。
- **安全边界**：机器人令牌、Webhook 和配对信息属于敏感数据；配置前应确认群成员和可执行权限。

## 14. 外观、输入与快捷键

- **主题与配色**：支持浅色、深色、系统模式以及主题预设和工作区覆盖。
- **输入偏好**：配置发送行为及其他输入体验选项。
- **个人偏好**：姓名、语言、时区等信息帮助智能体调整表达和时间解释。
- **快捷键**：在“设置 → 快捷键”查看当前平台的完整按键映射。
- **性能设置**：控制运行时预热、资源上限等性能选项；提高并行能力也会增加内存和处理器占用。

## 15. CLI、服务器与 WebUI

- **桌面应用**：提供完整图形界面、本地文件能力和系统集成。
- **CLI**：可从终端创建和运行会话，也可管理来源、技能、自动化、权限和主题。命令参考见本地 `craft-cli.md`。
- **服务器模式**：在受控主机上运行词元鸟服务，为远程客户端或自动化提供后端能力。
- **WebUI**：通过浏览器访问服务器工作区；浏览器环境不一定具备桌面端的所有本机能力。
- **远程服务器管理**：保存和切换服务器连接，连接前应验证地址、证书与身份认证。

## 16. 设置页面速查

- **应用**：通知、保持唤醒、浏览器工具、代理等全局行为。
- **偏好**：语言、姓名、时区和个人化信息。
- **AI**：连接、模型、默认值、测试和余额。
- **外观**：主题模式、配色和显示体验。
- **输入**：消息输入和发送偏好。
- **工作区**：工作区级默认配置。
- **提示词 / 提示词总览**：维护并检查工作区提示内容。
- **权限**：执行模式和细粒度规则。
- **工具**：内置与来源工具、来源说明要求。
- **性能**：运行时资源与预热策略。
- **功能指南**：当前这份总览以及随应用内置的详细本地参考。
- **标签**：标签定义、层级和值规则。
- **消息**：外部消息渠道配置。
- **远程服务器**：远端词元鸟服务连接。
- **协作**：工作区协作能力管理。
- **服务器**：本机服务器和 WebUI 相关设置。
- **快捷键**：完整键盘操作列表。

## 17. 本地文档位置

所有随应用提供的文档都在 `~/.tokenbird/docs/`。这些文件来自安装包中的 `resources/docs/`，词元鸟启动时会用当前版本重新同步，因此不应直接在同步目录里保存个人笔记。需要自定义说明时，请放到工作区或来源自己的文档中。

遇到问题时建议按以下顺序检查：

1. 打开“设置 → 功能指南”，搜索对应功能的本地技术参考。
2. 检查当前工作区、AI 连接、权限模式和相关来源是否启用。
3. 查看错误消息和应用日志，区分配置问题、权限问题、网络问题与上游服务问题。
4. 对会产生外部修改的操作先用只读方式验证目标和范围。
