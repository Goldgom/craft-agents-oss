# Android 与 Windows 功能对照

更新：2026-10-06。Android 默认进入本机聊天，可在菜单底部切换服务器；保留浅色、深色和系统主题。

## 已接入的功能

| 功能 | Android 入口 / 实现 |
| --- | --- |
| 历史、置顶、标记、归档、标签 | 侧栏与历史列表；最近只显示有消息的会话 |
| 会话看板 | 侧栏「会话看板」；共用 Windows 看板页面 |
| 页面库 | 侧栏「页面库」；共用页面管理接口 |
| 技能、数据源、项目 | 先打开列表，再进入详情；技能文件可下载，目录可浏览 |
| 定时任务、事件自动化、脚本监控、智能体 | 侧栏常用 / 更多功能；共用服务器接口 |
| 用量、充值、消息集成 | 更多功能与设置；充值在系统浏览器打开；消息集成需要启用网关的服务器 |
| 画布 | 侧栏创作工具；绘画、图层、图像导入、工程保存、PNG 导出，AI 需模型连接 |
| 思维导图 | 侧栏创作工具；浏览工作目录、导图文件读写、draw.io 编辑与导出，AI 需模型连接 |
| 超级智能体 | 侧栏创作工具；共用 Windows 页面和服务器任务接口 |
| 文件与附件 | 系统选择器读取手机文件；服务器文件下载到系统选择的保存位置 |
| 对话导出 | Markdown、Word、PNG 使用系统保存选择器；PDF 使用 Android 打印面板，可选择保存 PDF |
| 备份导出 / 导入 | 设置 → 数据与运行；ZIP 在设备与当前服务器间传输 |
| 工作区 | 顶部选择、切换、创建；切换后重新连接相应工作区 |
| 全屏弹窗 | 画布配置、历史、确认、目录选择和底部选择面板统一全屏；适配键盘可见区域，返回键逐层关闭；保留浅色与深色主题 |
| 系统通知 | Android 通知，点击返回会话；需通知权限，应用进程运行期间有效 |
| 保持亮屏 | 设置 → 数据与运行；只在任务处理中保持屏幕亮起 |
| 同一服务器的会话协作与迁移 | 共用协作接口、会话导入导出接口 |

画布和导图的会话索引、图像历史保存在 WebView IndexedDB。原生壳会复用本地 HTTP 端口，以保持重启后的存储来源一致；端口被占用时会回退到新端口，旧来源的数据不会自动迁移。

## 平台限制与未补齐部分

| 功能 | 当前限制 |
| --- | --- |
| Claude / Codex 原生桌面运行时 | Android bionic 不能直接运行 Windows/glibc 可执行文件；使用支持相应运行时的服务器 |
| Windows 内置浏览器与浏览器自动化 | 未实现 Android BrowserPaneManager；普通链接在系统浏览器打开 |
| 多服务器协作中继 | 依赖 Electron 主进程中继，Android 尚未实现；同服务器协作可用 |
| SFTP 客户端 | 尚未实现 Android SFTP；操作返回明确说明，不能冒充传输成功 |
| Windows 原生凭据库 | 不读取 DPAPI / Electron safeStorage；Android 在模型与数据源配置中管理凭据 |
| 工作区删除 | 尚未接入 Android 删除流程 |
| Office 转换、Sharp、ripgrep、Visio 导出 | 本机包未包含全部桌面工具；需要具备对应依赖的服务器 |
| 后台持续运行 | 尚未添加前台服务，系统杀进程后不能保证本地任务和通知继续运行 |
| 本机消息网关 | 本机精简包不包含消息网关；显示切换服务器入口，不挂载缺少接口的配置页 |
| 大文件 | 设备保存最大 64 MB；备份传输最大 50 MB；对话长图最大 1000 × 12000 像素，超限提示改用 PDF |

PDF 导出结果表示打印面板已打开，最终保存和取消由系统面板决定；不会返回虚构的文件路径。服务器模式下浏览的是服务器目录，不是手机共享存储。

## 验证

构建：`apps/android/build.ps1 -SkipToolchainInstall -SkipServerRuntimeDownload -DebugApplicationIdSuffix .dev`。
调试包：`dist/android/tokenbird-debug-device.apk`，独立包名 `top.goldgom.tokenbird.dev`，不覆盖或删除正式版数据。

自动检查包括共享导出格式、导图读写与符号链接边界、协议通道及客户端接口一致性；真机验证记录放在 `dist/android-ui-qa/parity-verification.md`。
